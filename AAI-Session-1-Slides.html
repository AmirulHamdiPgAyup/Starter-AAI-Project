Prompting 101

How to write a good prompt for everyday work in chat. Prompting the agent to build software is vibe coding, after lunch.

50 minTalk + hands-on
Prompting · The idea

A good prompt has four parts

Context

Who you are and what it is for.

Act as an HR officer.
For new staff.

Task

The one thing you want done.

Summarise this memo.
Compare these two options.

Constraints

Tone, length and language.

Friendly. No jargon.
Under 120 words.
Formal Bahasa Melayu.

Output

The shape you want back.

A table: item, owner, due date.
5 bullet points.

Leave a part out and the AI fills it in with a guess. Next: the four parts in one real prompt.

Prompting · The four parts in an example

Same request, with and without the four parts

Weak prompt
Write an email about the survey.
Result

“Hi all, I wanted to reach out about the survey. Please let me know if you have any questions…”

Generic. Which survey? Who is it for? What should they do?

All four parts
ContextI work in HR at a government agency.
TaskWrite an email reminding staff to finish the staff survey by Friday.
ConstraintsFriendly and short. Under 80 words.
OutputGive me 2 versions, each with a subject line.
Result

“Subject: Staff survey closes this Friday. Dear colleagues, please take five minutes to complete…”

Specific, ready to review and send.

Prompting · When it goes wrong

Wrong result? Find the missing part

“Too generic”
Write a notice about the new parking rules.

Add context: “I am an admin officer at a government office. The notice goes to all staff.”

“Not what I meant”
Help me with the leave report.

Add a task: “Summarise the leave report in 5 bullet points for my director.”

“Too long, too casual”
Explain our new password policy.

Add constraints: “Formal tone. Under 80 words. For staff who are not technical.”

“Wrong shape”
List the training sessions for next month.

Add output: “Put them in a table with three columns: session, date, room.”

Don’t start over. Add the missing part and ask again in the same chat.

Prompting · Use your own text

Give it the text. Tell it to stay inside it.

Without the text

"Summarise our leave policy."

It never saw your policy, so it guesses what a typical policy says.

With the text
Here is our policy: [paste]. Summarise it in 5 bullets for new staff. Use only this text. If something is not in it, say so. Quote the line you used for each bullet.
Paste the text in"Use only this text""If it's not there, say so"Ask for quotes

Public or made-up text only. Never paste real or sensitive data.

Prompting · Show an example

Show it what good looks like

Tell only
Write a one-line status update for the monthly report.

The style is a guess.

Tell, then show
Write one-line status updates in this style. Example 1: "Leave form: done, waiting for review." Example 2: "Login page: in progress, about 60%." Now write one for: the monthly report.

It copies the style, length and shape.

2 or 3 examples is enoughMake them different from each other"Same style as these"

An example is the quickest way to set tone, length and format.

Prompting · Label the parts

Keep your text and your instructions apart

Mixed up
Summarise this make it short for my manager here is the memo: [long memo text] and use plain words please

Where does the memo end and the request start?

Labelled
Memo: [paste the memo]   Task: Summarise the memo for my manager.   Rules: 5 bullets, plain words.

Each part has a name.

Name each partLong text first, request lastUse the same labels each time
Prompting · Good habits

Four habits for better answers

Ask it to ask you

“I need a short guide for new staff. Ask me 3 questions first.”

Go in steps

“Outline first. I will approve it, then you write.”

Think first

“Think it through step by step, then give the final answer.”

Improve in rounds

“List 2 weak points in your draft, then rewrite it.”

Follow-ups: “shorter”, “more formal”Change one thing at a timeNew topic = new chat
Cheat sheet · prompting

Before you press Send

Context. Did I say who I am and what it is for?

Task. Is it one clear request?

Limits. Did I give length, tone and audience?

Shape. Did I say bullets, table or email?

Example. Did I show one if the style matters?

Text. Did I paste what it should use?

Honesty. Did I say "tell me if you are not sure"?

Safety. Did I leave out real or sensitive data?

Based on Anthropic's prompting guide and MIT Sloan EdTech, "Effective Prompts".

Before you use it · what a quick check catches

Always check the result

Facts

The memo cites a rule. Does it exist? Find the source.

Names & titles

“Dear Mr Nurul”, but the supervisor is a woman.

Numbers & dates

“3 days from 5 to 8 June” is 4 days.

Real data

A real IC number slipped into the draft. Remove it.

A two-minute check can save you an embarrassing email.

Activity · 10 min · on your own · made-up details only

Pick two, run them, then check the result

I need to plan a half-day team meeting. Ask me 5 questions first, one at a time. Then write the agenda as a table: time, topic, owner.

Look for: Does it ask one question at a time? Is the table what you asked for?

Git · The idea

    
Git keeps every version of your files

    

      
Version 1first draft

      

      
Version 2add summary

      

      
Version 3fix typos · latest

    

    
Each save point is a commit. It records who changed what, and when. Go back to any one.

    

      
Documents
Policies, reports and meeting notes. See what changed in each version.

      
Writing
An author keeps every draft of a chapter, and tries a new ending safely.

      
Teams
Several people edit the same files without overwriting each other.

      
Code
The most common use, and the one that matters most with AI.

    

    
Git is not only for programmers. It works best with text files such as code, Markdown and plain text. It can store Word and Excel files, but cannot show what changed inside them.
